## Agent skills

### Issue tracker

Issues are tracked as GitHub issues on `ungkuamer/saringan`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) plus supplementary labels `prd` and `implementations`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — one `CONTEXT.md` at the repo root, decisions in `docs/adr/`. See `docs/agents/domain.md`.
